## Известные границы «окончательно»

Разделение полное в коде, входе, данных, выкатке, проверках и документах. В двух
местах оно останавливается, и это известно заранее.

**Прокси общий.** Два блока — для `finance.selfstudio.se` и для
`finance.test.selfstudio.se` — остаются в файле `Caddyfile.edge` платформы: у
одной машины один порт 443, и занимает его прокси платформы. Следствия:

- любая смена имени или порта Money — это hotfix платформы и пересоздание
  прокси, при котором все имена пропадают на несколько секунд;
- ошибка в этом файле роняет все имена обоих продуктов, поэтому перед каждым
  пересозданием файл проверяется (`docs/deploy.md`, «The edge»);
- «платформа больше не отдаёт Money» будет верно для её кода и базы, но не для
  прокси. Сервер, диск, память и root у двух продуктов тоже общие.

**Страница заморожена.** До передачи она не правится, поэтому:

- на закрытой двери она по-прежнему пишет «Сначала войдите в платформу» и
  «Money открывается под тем же входом, что и вся платформа» (`index.html:713`),
  а в «Настройках» — «На сервере студии, под входом платформы»
  (`index.html:1352`). Сервис прячет первое: без входа страница не отдаётся, и
  человек попадает на собственный `/login` Money. Второе фаундеры увидят;
- в ней **нет ссылки «Выйти»** — выход только по адресу `/login`;
- в ней **нет отметки стенда** — тест и прод внутри страницы выглядят одинаково;
  различаются только страницы входа.

Эти три правки — **первые задачи по странице, как только заморозка снята.**
Туда же: собственный «Загрузить данные из файла» страницы работает и на тесте,
так что «настоящих данных на тесте нет» держится на правиле и на ночной
очистке, а не на замке.

## Правила про настоящие данные

- Настоящая книга — выписки и план — **никогда не попадает в git.** `data/` в
  `.gitignore`; ничего из неё не цитируется в коммитах, документах и тестах.
- Настоящие данные **никогда не попадают на тестовый стенд.** Он заполняется
  только выдуманной студией из `scripts/money-demo.mjs`.
- Заметки дизайна с цифрами из настоящих выписок **остаются вне git** (`design/`
  в `.gitignore`). В документы этого репозитория настоящие суммы и число строк
  не переносятся — в том числе при переносе главы из handoff платформы.
- **Папка на Mac, где лежит `data/`, — не рабочая копия.** Она идёт за `main`,
  обновляется только `git pull --ff-only` и только по слову Мики. В ней не
  запускают `git clean`, сборки Docker, монтирование и тесты. Сессия не читает
  ничего под `~/Desktop`. Работа идёт в отдельной копии репозитория, где `data/`
  нет; тесты рядом с `data/` сами откажутся запускаться.
- **Файл, выгруженный с прода**, лежит на Mac вне любого репозитория, не идёт
  через чат и не копируется на диск сервера.
- На сервере сессия не открывает файлы в `/var/lib/money/prod`. Команды `ctl`
  печатают количества и размеры, не содержимое.
- **Сессия никогда не запускает `invite`.** Ссылку для входа выдаёт человек.
  Пароли, ссылки и ключи через чат не проходят.
- До шага 16 **нельзя восстанавливать дамп прода платформы на её тестовый
  стенд**: он принесёт туда таблицы Money с настоящими выписками.

## Страница: кто её сейчас правит

Другая сессия заканчивает итерацию 2 страницы в ветке платформы
`feature/money-live2`. Она передаст сюда **целиком** три файла: `index.html`,
`scripts/money-checks.mjs`, `scripts/money-demo.mjs`. До передачи эти файлы
здесь не правятся: любая правка была бы затёрта. После передачи страница

## Цикл работы

Заработает, когда появятся стенды; сейчас действует только первый пункт.

1. **Правка** — в своём worktree или отдельной копии, ветка `feature/<тема>`.
   Коммит и push сразу. Перед этим: `python3 -m unittest discover -s tests -t .`
2. **В тест:** слить в `develop`, push,
   `ssh root@204.168.164.31 money-deploy-test`.
3. **Мика смотрит** на `https://finance.test.selfstudio.se`.
4. **На прод — только по слову Мики:** релиз с тегом и
   `ssh root@204.168.164.31 money-deploy`.

На Mac — только тесты на Python: 8 ГБ памяти, рядом работают другие сессии.
Docker, node и браузер — в CI.
